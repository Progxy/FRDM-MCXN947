# ELS Random Value Demo

This directory contains a simple demonstration application for the MCXN947 that uses the EdgeLock Secure Enclave (ELS) random-number functionality and prints the generated value to the debug console.

## Hardware Configuration
* **MCU**: MCXN947.
* **Interface**: Debug console over the board’s configured serial connection.

## Demo Details
The application initializes the ELS random-number functionality, requests a value, and prints it to the debug console. The value is generated by the module.

## Build and Flash
```bash
make flash
```

## Expected Behavior
Upon power-on or reset, the application initializes the ELS random-number functionality and continously prints a generated value to the debug console.

To read the output, use the Python script in `utilities/debug_console.py`.
